# Coconut Cleaning Co. — pages opened from the Coconut Crew app

Static pages opened from the Coconut Crew app (Resources tab). Hosted on GitHub Pages.

- `training/urine-decontamination/` — Urine decontamination, step by step (interactive).
- `tools/price-sheet/` — Price Sheet Calculator + Coconut Club prescription. The Club tab ends with a customer signature box; submitting sends a signed PDF to the office and copies the customer. Built from the artifact source by `tools/build_price_sheet_page.py` in the coconut-crew repo.
- `shared/signature-pad.js` — signature box and the submit helper.
